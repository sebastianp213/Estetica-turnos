# Estética Turnos

Sistema web de gestión de turnos para un centro de estética.

## Descripción

Estética Turnos es una aplicación web que permite administrar las reservas de un centro de estética. Los clientes pueden consultar tratamientos, profesionales y horarios disponibles para reservar sus turnos.

El sistema también cuenta con un sector para profesionales y otro para administradores, con diferentes permisos y funcionalidades.

## Funcionalidades

### Clientes
- Registro e inicio de sesión.
- Consulta de tratamientos disponibles.
- Consulta de profesionales.
- Visualización de horarios disponibles.
- Reserva y cancelación de turnos.
- Consulta del historial de reservas.

### Profesionales
- Inicio de sesión.
- Consulta de agenda personal.
- Visualización de turnos asignados.
- Actualización del estado de los turnos.

### Administradores
- Gestión de tratamientos y precios.
- Gestión de profesionales.
- Configuración de horarios de atención.
- Administración de reservas.
- Gestión de usuarios.
